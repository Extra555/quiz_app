# Quizy MVP — структура проекта

- `frontend/` — React/Vite клиент и будущие публичные ассеты.
- `backend/` — Node.js API и Socket.IO сервер.
- `database/` — PostgreSQL-схема, миграции и начальные данные.
- `app/help_materials/` — визуальные референсы; не являются обязательными runtime-ассетами.

Существующий Vite-прототип в `app/` сохранён как исходный материал; рабочее приложение находится в `frontend/` и `backend/`.
