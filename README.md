# Quizy MVP

Игровая платформа для создания и проведения квизов в реальном времени. Интерфейс выполнен в яркой мультяшной эстетике: неоновый фон, объёмные панели, глянцевые кнопки и цветные игровые ответы.

## Возможности

- регистрация и JWT-авторизация;
- конструктор текстовых вопросов и вопросов с изображением;
- одиночный и множественный выбор;
- комнаты по шестизначному коду;
- Socket.IO-синхронизация, серверный таймер и переподключение игрока;
- начисление очков, победитель и лидерборд;
- личный кабинет с созданными квизами и историей результатов;
- адаптивная вёрстка для компьютеров и телефонов.

## Запуск

Требуется Node.js 20+.

```bash
npm run install:all
copy backend\.env.example backend\.env
npm run dev
```

Откройте `http://localhost:5173`. API работает на `http://localhost:3001`, проверка состояния — `http://localhost:3001/api/health`.

Для production-сборки клиента:

```bash
npm run build
npm test
```

## PostgreSQL

Создайте базу `quizy`, задайте `DATABASE_URL` в `backend/.env` и примените схему:

```bash
psql "%DATABASE_URL%" -f database/schema.sql
```

Схема включает пользователей, квизы, вопросы, игровые сессии и результаты. Текущая локальная MVP-конфигурация API использует оперативное хранилище, поэтому запускается без внешних сервисов; SQL-схема подготовлена для подключения постоянного repository-адаптера. При перезапуске локального API демонстрационные данные очищаются.

## Структура

```text
frontend/              React 19 + Vite
  src/App.jsx          экраны и игровой UI
  src/styles.css       дизайн-система Quizy
backend/               Express + Socket.IO
  src/app.js           REST API
  src/realtime.js      игровой realtime-движок
  src/store.js         локальное MVP-хранилище
database/schema.sql    PostgreSQL DDL
app/help_materials/    исходный mood board
```

## Основной сценарий

1. Ведущий регистрируется и создаёт квиз.
2. После сохранения появляется шестизначный код комнаты.
3. Игроки вводят код и псевдоним на главной странице.
4. Ведущий запускает вопросы и переключает раунды.
5. Сервер сверяет ответы, начисляет очки и показывает итоговый рейтинг.

При перезагрузке страницы игрок возвращается с прежним `playerId`; его очки и место в текущей комнате сохраняются.
